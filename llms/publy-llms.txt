# PUBLY (퍼블리)

> PUBLY is a Korean career-development and content membership platform. It sells a subscription
> Career Membership that gives working professionals curated career content, series, templates and
> job-transition guides, personalized daily recommendations by career stage, an AI assistant feature
> (Perdy, beta), and a newsletter. The membership business was acquired by NEWNEEK Co., Ltd. (뉴닉)
> in June 2024 and continues to operate at publy.co.

## API surface

- `https://publy.co/openapi.json`, `/openapi.yaml`, `/swagger.json`, `/v1/openapi.json`,

  agent-card.json, agent.json) — all HTTP 404
- `api.publy.co`, `docs.publy.co`, `developer.publy.co`, `status.publy.co` — do not resolve
- no first-party SDK on npm, PyPI, or GitHub; no public Postman workspace

`https://publy.co/robots.txt` declares `Disallow: /api/**`, which indicates the consumer web
application is backed by a first-party JSON API under that path. It is an internal application
backend: it is undocumented, unversioned publicly, disallowed to crawlers, and was not probed.
Agents should treat PUBLY as a human-facing subscription product, not an integrable API.
